# Bookend Weaver

모임을 위한 웹 기반 조 편성 자동화 및 회원 관리 대시보드입니다. 
과거 조 편성 기록을 분석하여 부원 간의 중복 매칭을 최소화하고, 관리자의 수동 조작 편의성을 고려하여 설계되었습니다.

## 🛠 Tech Stack

**Frontend**
* React, React Router DOM
* Vite
* Vanilla CSS (Custom UI)

**Backend** (API Server)
* Java, Spring Boot
* Spring Security (JWT)
* Spring Data JPA

**Infrastructure & Deployment**
* **Frontend**: Vercel (`vercel.json`의 Rewrite 설정을 통해 백엔드 API와 Proxy 연결)
* **Backend**: Render
